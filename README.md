# Sprint_7 — API Яндекс Самокат

Автотесты учебного сервиса: https://qa-scooter.education-services.ru
Документация: https://qa-scooter.education-services.ru/docs/


## Структура

- `urls.py` — адреса ручек и таймаут 20 секунд.
- `data.py` — сообщения ошибок и функции подготовки новых данных.
- `conftest.py` — фикстуры подготовки и очистки данных.
- `tests/test_create_courier.py` — создание курьера.
- `tests/test_login_courier.py` — авторизация курьера.
- `tests/test_create_order.py` — создание заказа.
- `tests/test_list_orders.py` — получение списка заказов.
- `REPORT.md` — результаты запуска и известная проблема стенда.


## Как читать фикстуры и тесты

1. `new_courier` готовит уникальные логин и пароль. Код до `yield` выполняется
   до теста, код после `yield` — после него, даже если `assert` не прошёл.
   Фикстура пытается войти и удаляет курьера по полученному `id`.
   Ответ 404 при очистке допустим: негативный тест мог не создать курьера.
2. `registered_courier` использует `new_courier` и регистрирует курьера перед
   тестом. За удаление по-прежнему отвечает `new_courier`.
3. `login_data` возвращает отдельный словарь с логином и паролем созданного
   курьера. Изменения этого словаря не меняют данные для очистки.
4. `new_order` возвращает данные заказа. `order_tracks` возвращает пустой
   список: тест добавляет туда полученный `track`, после теста фикстура
   отменяет заказ. Ошибка отмены или удаления делает teardown неуспешным.
5. `.copy()` создаёт копию словаря, чтобы негативный тест мог удалить поле
   через `.pop()` или изменить значение, сохранив исходные данные для очистки.
6. `@pytest.mark.parametrize` запускает один метод несколько раз с разными
   значениями. `ids` задаёт понятные имена вариантов в результатах pytest.

`uuid4().hex` создаёт случайную строку для уникального логина.
